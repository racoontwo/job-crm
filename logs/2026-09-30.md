Spent the rest of the session diagnosing why MongoDB had silently been falling back to SQLite all week: the swallowed error was a raw TLS handshake failure (`ssl3_read_bytes: tlsv1 alert internal error`), reproduced identically with plain `openssl s_client` against the Atlas shard host to rule out Node/the driver, which turned out to be Atlas's Network Access allowlist rejecting the current IP rather than a paused cluster or a code issue. Decided to stay local-only for now rather than fix the allowlist immediately — commented out `MONGODB_URI` in `.env.local` and updated `components/DatabaseStatusToast.tsx` so the toast only warns when Mongo is configured-but-failing, staying silent when it's deliberately unconfigured, so the app doesn't nag about a cloud database it isn't currently trying to use.
